# CPU Scheduling Simulator

โปรแกรมจำลองการจัดสรรหน่วยประมวลผล (CPU Scheduling) ด้วยอัลกอริทึม
**FCFS**, **SJF แบบ Non-preemptive** และ **Round Robin** พร้อมแผนภาพ Gantt Chart
พัฒนาเป็น Web Application ด้วย HTML, CSS และ JavaScript ในไฟล์เดียว ไม่ต้องติดตั้งโปรแกรมเพิ่ม

---

## 1. วิธีเปิดใช้งานโปรแกรม

1. ดาวน์โหลดไฟล์ `index.html`
2. ดับเบิลคลิก `index.html` หรือคลิกขวา → Open with → **Google Chrome** หรือ **Microsoft Edge**
3. โปรแกรมเปิดได้ทันที ไม่ต้องใช้อินเทอร์เน็ต ไม่ต้องติดตั้งอะไรเพิ่ม และไม่อ้างอิงไฟล์หรือ path ใดในเครื่องผู้พัฒนา

> หมายเหตุ: ถ้าแตกไฟล์ zip ไว้ในโฟลเดอร์ที่ซิงค์กับ OneDrive แล้ว Explorer ค้าง ให้แตกไฟล์ไว้ที่โฟลเดอร์ปกติ เช่น `C:\cpu-scheduler` แทน

## 2. วิธีใช้งาน

1. **กำหนดจำนวนโปรเซส** กรอกจำนวน (เช่น 3, 5, 10) แล้วกด **สร้างช่องกรอกโปรเซส**
   ระบบจะสร้างโปรเซส P1 ถึง Pn ทุกโปรเซสมี Arrival Time (AT) = 0
   (เมื่อเปิดโปรแกรมครั้งแรก จะมีตัวอย่าง 4 โปรเซส BT = 6, 8, 7, 3 ใส่ไว้ให้)
2. **กำหนด Burst Time** ได้ 2 วิธี
   - กรอกเองทีละโปรเซส
   - กด **สุ่มค่า Burst Time (1-20)** ระบบจะสุ่มจำนวนเต็มบวก 1 ถึง 20 ให้ทุกโปรเซส
3. **เลือกอัลกอริทึม** จากรายการ
   - เปรียบเทียบทั้ง 3 อัลกอริทึม (แสดงผล FCFS, SJF, RR จากชุดข้อมูลเดียวกัน)
   - FCFS
   - SJF (Non-preemptive)
   - Round Robin
4. **กำหนด Time Quantum** (สำหรับ RR) ค่าเริ่มต้นคือ 2 เปลี่ยนได้ก่อนกดคำนวณ
5. กด **คำนวณและแสดงผลลัพธ์**

## 3. ผลลัพธ์ที่แสดง

แต่ละอัลกอริทึมแสดง
- **Gantt Chart** ลำดับการใช้ CPU พร้อมเวลาเริ่ม-จบของแต่ละช่วง
- **ตาราง** Process, AT, BT, ST, CT, TAT, WT
- **AVG WT** พร้อมวิธีคำนวณ เช่น `AVG WT = 13 ÷ 3 = 4.33`

สูตรที่ใช้

| ค่า | ความหมาย | สูตร |
|---|---|---|
| ST | Start Time เวลาที่ได้ CPU ครั้งแรก | จากการจำลอง |
| CT | Completion Time เวลาที่ทำงานเสร็จสมบูรณ์ | จากการจำลอง |
| TAT | Turnaround Time | TAT = CT − AT (AT = 0 จึงได้ TAT = CT) |
| WT | Waiting Time | WT = TAT − BT |
| AVG WT | Waiting Time เฉลี่ย | ผลรวม WT ÷ จำนวนโปรเซส |

## 4. หลักการทำงานของแต่ละอัลกอริทึม

| อัลกอริทึม | หลักการ | ฟังก์ชันในโค้ด |
|---|---|---|
| FCFS | ทำตามลำดับที่มาถึง เนื่องจาก AT = 0 ทั้งหมด จึงเรียง P1, P2, …, Pn ทำจนเสร็จทีละตัว | `runFCFS()` |
| SJF (Non-preemptive) | เลือกโปรเซสที่ BT น้อยที่สุดก่อน ทำจนเสร็จไม่ถูกขัดจังหวะ ถ้า BT เท่ากันให้โปรเซสหมายเลขน้อยกว่าได้ก่อน | `runSJF()` |
| Round Robin | ให้แต่ละโปรเซสใช้ CPU ครั้งละไม่เกิน Time Quantum ถ้ายังไม่เสร็จให้รอรอบถัดไป วนจนทุกโปรเซสเสร็จ | `runRR()` |

> หมายเหตุ Round Robin: โค้ดวนตามลำดับ P1 → Pn ซ้ำทุกรอบแทนการใช้คิว
> ให้ผลเหมือนคิว FIFO เพราะโจทย์กำหนดให้ทุกโปรเซสมาถึงพร้อมกัน (AT = 0)
> หากโปรเซสมาถึงไม่พร้อมกัน จะต้องเปลี่ยนเป็นการใช้คิวจริง

## 5. โครงสร้างโปรแกรม

โปรแกรมอยู่ในไฟล์ `index.html` ไฟล์เดียว แบ่งเป็น 3 ส่วน

| ส่วน | รายละเอียด |
|---|---|
| `<style>` | การตกแต่งหน้าจอ การ์ด ตาราง และ Gantt Chart |
| HTML | ช่องกรอกจำนวนโปรเซส, ช่อง BT, ตัวเลือกอัลกอริทึม, Time Quantum, กล่องแจ้งเตือน และพื้นที่แสดงผล |
| `<script>` | ฟังก์ชันหลักตามตารางด้านล่าง |

| ฟังก์ชัน | หน้าที่ |
|---|---|
| `generateProcessInputs()` | สร้างช่องกรอก BT ของ P1 ถึง Pn |
| `randomizeBurstTimes()` | สุ่ม BT 1 ถึง 20 |
| `isPositiveInteger()` | ตรวจว่าค่าเป็นจำนวนเต็มบวก (รับเฉพาะตัวเลข 0-9 และมากกว่า 0) |
| `getValidatedInputs()` | ตรวจข้อมูลทั้งหมดก่อนคำนวณ |
| `runFCFS()`, `runSJF()`, `runRR()` | คำนวณ ST, CT, TAT, WT และข้อมูล Gantt Chart |
| `buildGanttHTML()`, `buildResultBlockHTML()` | สร้าง Gantt Chart และตารางผลลัพธ์ |
| `calculateScheduling()` | เรียกใช้อัลกอริทึมที่เลือกและแสดงผล |

## 6. การตรวจสอบข้อมูล

โปรแกรมแสดงข้อความแจ้งเตือนเมื่อ
- ไม่กรอกจำนวนโปรเซส
- จำนวนโปรเซสเป็น 0, ติดลบ, ทศนิยม หรือรูปแบบอื่นที่ไม่ใช่จำนวนเต็ม (เช่น `1e1`)
- กรอก Burst Time ไม่ครบทุกโปรเซส (ระบุว่าโปรเซสไหนยังไม่กรอก)
- Burst Time ไม่ใช่จำนวนเต็มบวก
- Time Quantum ไม่ใช่จำนวนเต็มบวก
- เปลี่ยนจำนวนโปรเซสแต่ยังไม่กดสร้างช่องกรอกใหม่

และเมื่อแก้ BT, กดสุ่ม, แก้ Time Quantum หรือเปลี่ยนอัลกอริทึมหลังคำนวณแล้ว ผลลัพธ์เก่าจะถูกซ่อน เพื่อไม่ให้สับสนกับข้อมูลใหม่

## 7. กรณีทดสอบ

### กรณีที่ 1: กำหนด Burst Time เอง และเปรียบเทียบทั้งสามอัลกอริทึม (ตรวจด้วยการคำนวณมือ)

ข้อมูล: P1 = 5, P2 = 3, P3 = 8, Time Quantum = 2

**FCFS** ลำดับ P1 [0-5] → P2 [5-8] → P3 [8-16]

| Process | AT | BT | ST | CT | TAT | WT |
|---|---|---|---|---|---|---|
| P1 | 0 | 5 | 0 | 5 | 5 | 0 |
| P2 | 0 | 3 | 5 | 8 | 8 | 5 |
| P3 | 0 | 8 | 8 | 16 | 16 | 8 |

AVG WT = (0 + 5 + 8) ÷ 3 = 13 ÷ 3 = **4.33**

**SJF** เรียงตาม BT: P2 (3) [0-3] → P1 (5) [3-8] → P3 (8) [8-16]

| Process | AT | BT | ST | CT | TAT | WT |
|---|---|---|---|---|---|---|
| P1 | 0 | 5 | 3 | 8 | 8 | 3 |
| P2 | 0 | 3 | 0 | 3 | 3 | 0 |
| P3 | 0 | 8 | 8 | 16 | 16 | 8 |

AVG WT = (3 + 0 + 8) ÷ 3 = 11 ÷ 3 = **3.67**

**Round Robin (q = 2)**

| ช่วงเวลา | 0-2 | 2-4 | 4-6 | 6-8 | 8-9 | 9-11 | 11-12 | 12-14 | 14-16 |
|---|---|---|---|---|---|---|---|---|---|
| โปรเซส | P1 | P2 | P3 | P1 | P2 | P3 | P1 | P3 | P3 |
| BT คงเหลือหลังรัน | 3 | 1 | 6 | 1 | 0 ✔ | 4 | 0 ✔ | 2 | 0 ✔ |

| Process | AT | BT | ST | CT | TAT | WT |
|---|---|---|---|---|---|---|
| P1 | 0 | 5 | 0 | 12 | 12 | 7 |
| P2 | 0 | 3 | 2 | 9 | 9 | 6 |
| P3 | 0 | 8 | 4 | 16 | 16 | 8 |

AVG WT = (7 + 6 + 8) ÷ 3 = 21 ÷ 3 = **7.00**

**สรุป:** SJF ให้ AVG WT ต่ำที่สุด (3.67) เพราะให้งานสั้นทำก่อน งานสั้นจึงรอน้อย
ส่วน RR ให้ AVG WT สูงสุด (7.00) แต่ทุกโปรเซสได้เริ่มทำงานเร็ว (ST = 0, 2, 4)
ผลที่โปรแกรมแสดงตรงกับการคำนวณมือทุกค่า

### กรณีที่ 2: ให้ระบบสุ่ม Burst Time

1. กรอกจำนวนโปรเซส 10 แล้วกดสร้างช่องกรอก
2. กด **สุ่มค่า Burst Time (1-20)**
3. เลือก "เปรียบเทียบทั้ง 3 อัลกอริทึม" แล้วกดคำนวณ

ผลที่คาดหวัง: ทุกโปรเซส P1 ถึง P10 มีค่า ST, CT, TAT, WT ครบทั้ง 3 อัลกอริทึม และ CT ของโปรเซสที่เสร็จท้ายสุดเท่ากับผลรวม BT ทั้งหมด

ค่าที่สุ่มได้จริง: _(กลุ่มกรอกค่า BT ที่สุ่มได้ และแนบภาพหน้าจอ)_

### กรณีที่ 3: ชุดข้อมูลเดิมกับ Round Robin แต่เปลี่ยน Time Quantum

ข้อมูล: P1 = 5, P2 = 3, P3 = 8

| Time Quantum | ST (P1, P2, P3) | CT (P1, P2, P3) | WT (P1, P2, P3) | AVG WT |
|---|---|---|---|---|
| 1 | 0, 1, 2 | 12, 8, 16 | 7, 5, 8 | 6.67 |
| 2 | 0, 2, 4 | 12, 9, 16 | 7, 6, 8 | 7.00 |
| 4 | 0, 4, 7 | 12, 7, 16 | 7, 4, 8 | 6.33 |

**สรุป:** Quantum ที่ต่างกันทำให้ลำดับการสลับงานต่างกัน และ AVG WT เปลี่ยนไป
ถ้า Quantum มากกว่าหรือเท่ากับ BT ที่มากที่สุด (เช่น q = 8) RR จะให้ผลเหมือน FCFS

### ข้อมูลตัวอย่างเพิ่มเติม (ค่าเริ่มต้นของโปรแกรม)

ข้อมูล: P1 = 6, P2 = 8, P3 = 7, P4 = 3, Time Quantum = 2

| อัลกอริทึม | CT (P1, P2, P3, P4) | WT (P1, P2, P3, P4) | AVG WT |
|---|---|---|---|
| FCFS | 6, 14, 21, 24 | 0, 6, 14, 21 | 10.25 |
| SJF | 9, 24, 16, 3 | 3, 16, 9, 0 | 7.00 |
| RR (q = 2) | 17, 23, 24, 15 | 11, 15, 17, 12 | 13.75 |
